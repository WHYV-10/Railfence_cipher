# Rail Fence Cipher

Aplikasi enkripsi dan dekripsi **Rail Fence Cipher** berbasis GUI, dibuat dengan Python dan Tkinter.

## Tentang Rail Fence Cipher
Rail Fence Cipher adalah cipher transposisi. Huruf-huruf tidak diganti, tetapi diacak posisinya. Teks ditulis zig-zag pada sejumlah "rail" (baris), lalu dibaca baris demi baris untuk menghasilkan teks sandi. Jumlah rail menjadi kuncinya.

## Fitur
- Enkripsi dan dekripsi teks
- Kunci berupa jumlah rail (angka)
- Visualisasi pola zig-zag dari teks asli
- Tombol salin hasil ke clipboard

## Cara Menjalankan
Pastikan Python 3 sudah terpasang (Tkinter sudah termasuk di Python).
